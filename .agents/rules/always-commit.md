# Regra: Sempre Fazer Commit no Git

- Ao finalizar qualquer funcionalidade, correção de bug ou refatoração, realize o commit de forma imediata e proativa no Git.
- O repositório deve permanecer com o working tree limpo ao responder ao usuário.
- Use mensagens claras e semânticas (ex: `feat: ...`, `fix: ...`, `refactor: ...`).
- Valide que o build (`npm run build`) está passando com sucesso antes de finalizar.
