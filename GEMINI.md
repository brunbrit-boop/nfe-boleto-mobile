# Diretrizes do Projeto - NFe Boleto Mobile

## Regra Obrigatória: Sempre Fazer Commit no Git
- **Sempre realizar commit** de forma proativa ao concluir qualquer alteração de código, correção de bugs, criação de componentes ou refatoração.
- **Não deixar alterações pendentes** (unstaged/uncommitted) no working tree ao responder ao usuário.
- Utilizar mensagens semânticas seguindo o padrão Conventional Commits (ex: `feat(...)`, `fix(...)`, `refactor(...)`).
- Sempre verificar se o build (`npm run build`) compila sem erros antes de concluir a tarefa.

## Design e Usabilidade (App Design Master)
- Seguir as diretrizes do `app-design-master`: interfaces limpas, botões e ações com textos curtos (máximo 2 a 3 palavras), sem textos explicativos secundários desnecessários, priorizando ícones e layouts modernos para telas compactas e mobile.
